# M1 Skeleton Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A running Cargo workspace where a CLI turn flows through the full symbolic engine loop (project → emit → guard → perform → settle → reply) using scripted stand-ins for both LLMs — proving the architecture with zero network calls.

**Architecture:** Event-sourced core: every turn appends typed, hash-chained events to a per-session log; state is a fold; the engine owns control flow and calls `Emitter`/`Replier`/`Tool` plugins behind traits defined in a tiny `core` crate. Assembly uses a Bevy-style `HarnessBuilder` with exactly-one and collection slots.

**Tech Stack:** Rust 2021, tokio (rt-multi-thread, macros, io-util, io-std), async-trait, serde + serde_json, thiserror, sha2 (hash chain only).

**Spec:** `docs/superpowers/specs/2026-09-01-neuro-symbolic-harness-design.md`

## Global Constraints

- Workspace member crates in M1: `crates/core`, `crates/engine`, `crates/channel-cli`, `app`. Other crates from the spec (`provenance`, `llm`, `components-std`, `memory-sqlite`, `channel-telegram`) are M2+ — do NOT create them.
- `core` dependencies: `serde` (derive), `serde_json`, `async-trait`, `thiserror`, `sha2` — nothing else. (`sha2` is a documented addition to the spec's list; the hash chain lives in `core::event`.)
- `core` must not depend on tokio. Async traits use `async_trait`; tests needing a runtime live in crates that already have tokio.
- Package names are prefixed `ns-` (`ns-core`, `ns-engine`, `ns-channel-cli`, `ns-app`); lib names are `core` is not a valid lib name conflict-wise, so set `lib.name` = `nscore`, `nsengine`, `nschannel_cli`. Import as `use nscore::...`.
- Every event append goes through `EventLog::append` (it computes `prev_hash`); constructing `Event` by hand outside `core::event` is forbidden.
- Every turn must terminate with a `Replied` event — including all error paths.
- Tool boundary is JSON-shaped: args are `serde_json::Value`, results are `ToolOutput`.
- TDD per task: write the failing test, watch it fail, implement, watch it pass, commit. Run tests with `cargo test -p <crate>` from the repo root.
- Commit after every task with the message given in the task (append the standard `Co-Authored-By: Claude Fable 5 <noreply@anthropic.com>` trailer).
- Git identity is not configured globally on this machine: run commits as `git -c user.name="Martin" -c user.email="hrabal@jtjdreams.cz" commit ...`.

#[serde(tag = "type")]

    Replied { text: String },
    // Extended in Task 3 with: Proposed, Rejected, ToolCalled, ToolReturned,
    // PendingConfirmation, Confirmed, Corrected, Settled.

pub struct Event {
    pub id: EventId,
    pub parent: Option<EventId>,
    #[serde(with = "hash_serde")]
    pub prev_hash: [u8; 32],
    pub turn: u32,
    pub at: Timestamp,
    pub kind: EventKind,

/// Serialize [u8; 32] as lowercase hex.
mod hash_serde {
    use serde::{Deserialize, Deserializer, Serializer};

    pub fn serialize<S: Serializer>(h: &[u8; 32], s: S) -> Result<S::Ok, S::Error> {
        let hex: String = h.iter().map(|b| format!("{b:02x}")).collect();
        s.serialize_str(&hex)
    }

    pub fn deserialize<'de, D: Deserializer<'de>>(d: D) -> Result<[u8; 32], D::Error> {
        let s = String::deserialize(d)?;
        if s.len() != 64 {
            return Err(serde::de::Error::custom("hash must be 64 hex chars"));
        }
        let mut out = [0u8; 32];
        for i in 0..32 {
            out[i] = u8::from_str_radix(&s[2 * i..2 * i + 2], 16)
                .map_err(serde::de::Error::custom)?;
        }
        Ok(out)
    }
}

use crate::event::EventId;
use serde::{Deserialize, Serialize};
use sha2::{Digest, Sha256};

/// Declaration order defines Ord: External is LEAST trusted.
#[derive(Debug, Clone, Copy, PartialEq, Eq, PartialOrd, Ord, Serialize, Deserialize)]
pub enum Trust {
    External,
    System,
    User,
}

/// Minimum trust across a chain; empty chain is User (nothing untrusted involved).
pub fn min_trust(chain: &[Trust]) -> Trust {
    chain.iter().copied().min().unwrap_or(Trust::User)
}

#[derive(Debug, Clone, PartialEq, Serialize, Deserialize)]
#[serde(tag = "type")]
pub enum Provenance {
    Constant,
    UserInput { turn: u32, start: u32, end: u32 },
    CopiedOutput { call: EventId, path: String },
    Transform { func: String, inputs: Vec<Provenance> },
    Residual,
}

#[derive(Debug, Clone, PartialEq, Serialize, Deserialize)]
pub struct TaggedValue {
    pub value: serde_json::Value,
    pub prov: Provenance,
    pub trust: Trust,
}

#[derive(Debug, Clone, Copy, PartialEq, Eq, Hash, Serialize, Deserialize)]
pub struct ArtifactId(#[serde(with = "crate::event::hash_serde")] pub [u8; 32]);

impl ArtifactId {
    pub fn for_content(bytes: &[u8]) -> Self {
        let mut h = Sha256::new();
        h.update(bytes);
        ArtifactId(h.finalize().into())
    }
}

```rust
use sha2::{Digest, Sha256};

fn event_hash(e: &Event) -> [u8; 32] {
    let json = serde_json::to_vec(e).expect("event serialization is infallible");
    let mut h = Sha256::new();
    h.update(&json);
    h.finalize().into()
}

#[derive(Debug, Clone)]
pub struct EventLog {
    session: SessionId,
    events: Vec<Event>,
}

#[derive(Debug, thiserror::Error, PartialEq)]
pub enum ChainError {
    #[error("hash chain broken at event {id:?}")]
    BrokenAt { id: EventId },
}

impl EventLog {
    pub fn new(session: SessionId) -> Self {
        Self { session, events: Vec::new() }
    }

    pub fn from_events(session: SessionId, events: Vec<Event>) -> Self {
        Self { session, events }
    }

    pub fn session(&self) -> &SessionId { &self.session }
    pub fn events(&self) -> &[Event] { &self.events }

    pub fn next_id(&self) -> EventId {
        EventId(self.events.last().map(|e| e.id.0 + 1).unwrap_or(1))
    }

    pub fn append(&mut self, turn: u32, at: Timestamp, kind: EventKind) -> &Event {
        let prev_hash = self.events.last().map(event_hash).unwrap_or([0u8; 32]);
        let e = Event { id: self.next_id(), parent: None, prev_hash, turn, at, kind };
        self.events.push(e);
        self.events.last().unwrap()
    }

    pub fn verify_chain(&self) -> Result<(), ChainError> {
        let mut prev: Option<&Event> = None;
        for e in &self.events {
            let expected = prev.map(event_hash).unwrap_or([0u8; 32]);
            if e.prev_hash != expected {
                return Err(ChainError::BrokenAt { id: e.id });
            }
            prev = Some(e);
        }
        Ok(())
    }
}
```

    /// Outer loop: recv → run_turn → send, until channel closes.
    pub async fn run(&mut self) -> Result<(), EngineError>;

    #[error("store: {0}")] Store(#[from] nscore::StoreError),
    #[error("channel: {0}")] Channel(String),

`run_turn` algorithm (M1 — provenance classification is a stub that tags every arg `Provenance::Residual`, `Trust::User`; real classification is M3):

1. `load` events → `EventLog::from_events` → `turn = fold.turn + 1` → append `UserSaid`.
2. Loop up to `cfg.max_iterations`:
   a. `fold` → `SessionState`; `LegalActionSet` = all registered tools' specs (M1: no pruning).
   b. Build `EmitterContext { state_summary: state_summary(&s), recent_turns: last 6 of s.history, rejections_this_turn }`.
   c. `emitter.propose`. On `Err` → append `Rejected { proposal_of: EventId(0), reason: Malformed{..} }`, retry up to `max_emit_retries`, then break to fallback settle.
   d. Append `Proposed`; hold its id as `pid`.
   e. If `action == "respond_directly"` → append `Settled { policy: Generate }`, break loop.
   f. If `!legal.contains(action)` → append `Rejected { proposal_of: pid, reason: IllegalAction{..} }`, push reason string to `rejections_this_turn`, continue loop.
   g. Build `ClassifiedProposal` (stub classification of `args` object's top-level fields).
   h. Run every guard; first non-`Allow` wins. `Deny` → append `Rejected { GuardDenied }`, push reason, continue loop. `NeedsConfirmation` → append `PendingConfirmation { proposal_of: pid, staged: None }` then `Settled { policy: Verbatim { text: prompt } }`, break loop.
   i. Find the tool by name, append `ToolCalled` (with the classified args), `tool.call`; append `ToolReturned { call, outcome }` (map `ToolError` → `ToolOutcome::Err`). Continue loop (the scripted emitter will `respond_directly` next).
3. If the loop exhausted iterations or emitter retries without settling → append `Settled { policy: Verbatim { text: "Sorry, I couldn't complete that.".into() } }`.
4. Reply per policy: `Verbatim` → the text; `Template` → `format!("[{id}] {vars}")` (M1 placeholder-free minimal renderer, real templates M4); `Generate` → build `ReplyContext { persona: "".into(), facts: vec![], session_summary: state_summary(..), turn_trace }` where `turn_trace` = one line per this-turn event: `Proposed(echo)`, `Rejected(guard residual: ...)`, `ToolReturned(ok: echo: hi)` — then `replier.reply`; on `ReplyError` fall back to the `Verbatim` sorry-text.
5. Append `Replied`; `store.append(&sid, &log.events()[n_loaded..])` (only new events); return the text.
